GitHub sync

Sync off
Continuously backs up to a file in your GitHub repo, and pulls the latest whenever you open SACTA on another device. Use a private repo — this data includes names, IDs and amounts. Your token is stored only in this browser; it is never written into the hosted page or into your exported backups.
How to set it up (about 2 minutes)
1. Create a private repo on GitHub, e.g. sacta-data — it can be empty.
2. GitHub Settings → Developer settings → Fine-grained tokens → Generate new token.
3. Repository access → Only select repositories → pick your sacta-data repo.
4. Permissions → Repository permissions → Contents → Read and write. Generate and copy the github_pat_… token.
5. Paste the token, your username and the repo name above, then Connect & sync. Set an expiry you're comfortable with and re-paste a fresh token when it lapses.

Data

Your data lives in this browser (localStorage). It is not saved into the hosted file. Use Export to back it up or move to another computer, then Import there.
